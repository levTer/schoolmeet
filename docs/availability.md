# Почему сайт может не открываться без VPN и что с этим делать

Короткая версия: **чаще всего виноват не код, а две вещи вокруг него** — бесплатный
тариф Render, который усыпляет сервис, и сетевой узел Cloudflare, через который
Render отдаёт все сайты. Ниже — как отличить одно от другого за минуту и что делать.

## Шаг 0. Проверить, жив ли сервер

```bash
curl -sS https://schoolmeet-vb96.onrender.com/api/health
# {"ok":true,"checks":{"database":{"ok":true},"realtime":{"ok":true}},"uptimeSeconds":28,...}
```

- `uptimeSeconds` маленький (десятки секунд) → **инстанс только что проснулся**:
  именно этот случай описан в причине 1.
- Ответа нет вообще или соединение виснет на этапе TLS → причина 2.

## Причина 1. Бесплатный Render усыпляет сервис (исправлено)

Бесплатный инстанс Render засыпает примерно через 15 минут без запросов. Первый
посетитель после сна видит не школу, а заставку Render и ждёт 30–90 секунд —
и часто успевает решить, что «сайт не работает». С VPN ожидание ощущается короче,
но дело не в VPN, а в холодном старте.

**Что сделано:** `.github/workflows/keepalive.yml` каждые 5 минут дергает
`/api/health`, поэтому инстанс не засыпает. Бесплатные 750 инстанс-часов Render
покрывают один сервис, включённый круглосуточно (в месяце максимум 744 часа), то
есть пинг не выводит за пределы бесплатного тарифа.

Ограничения: расписания в GitHub Actions работают только из ветки по умолчанию
(`main`); после 60 дней без активности в репозитории GitHub отключает cron —
любой коммит включает его снова. Проверить вручную:
Actions → **Keep web service awake** → Run workflow.

## Причина 2. Домен за Cloudflare и ограничения российских сетей

`schoolmeet-vb96.onrender.com` резолвится в `*.cdn.cloudflare.net` — Render отдаёт
все проекты через Cloudflare. С 2024 года часть российских операторов ограничивает
соединения к Cloudflare (в первую очередь из-за расширения TLS ECH, которое
Cloudflare включает по умолчанию): снаружи сайт отвечает, из РФ без VPN —
«соединение сброшено» или бесконечная загрузка.

На зоне `onrender.com` вы не управляете настройками Cloudflare (это зона Render),
поэтому отключить ECH или поменять IP нельзя. Варианты, от простого к надёжному:

### Вариант A. Свой домен (полчаса, 200–800 ₽/год)

1. Купить домен у регистратора, который принимает российские карты
   (`reg.ru`, `timeweb`, `beget`).
2. В Render: **Settings → Custom Domains → Add**, привязать домен (Render выдаст
   CNAME/`A`-запись).
3. В DNS регистратора прописать выданные записи и подождать выпуск сертификата
   (Render делает это сам, обычно 5–15 минут).
4. Прописать новый адрес в переменных окружения сервиса: `NEXTAUTH_URL` и
   `NEXT_PUBLIC_APP_URL` (если используется) — иначе OAuth/callback и абсолютные
   ссылки останутся на старом домене.
5. Проверить из мобильного интернета **без VPN**.

Помогает не всегда: домен всё равно обслуживает Cloudflare Render'а, и если
конкретный узел попал под блокировку у вашего оператора, симптом останется.

### Вариант B. Перенос на российский хостинг (надёжно)

Приложение самодостаточно: Next.js + Socket.IO на одном порту + PostgreSQL
(`server.ts`), файлы ДЗ — локальный каталог `UPLOAD_DIR`. Ему нужен обычный VPS с
Node.js 22 и PostgreSQL 16 — его даёт любой российский провайдер
(`timeweb.cloud`, `beget.com`, `selectel.ru`, `reg.ru`) за 200–400 ₽/месяц, и
такой адрес доступен из РФ без VPN.

Порядок:

1. Создать VPS (Ubuntu 24.04, 2 vCPU / 2 ГБ RAM достаточно) и домен.
2. Установить Node.js 22, PostgreSQL 16 и Caddy (Caddy сам выпускает HTTPS).
3. Склонировать репозиторий, заполнить `.env` (образец — `.env.example`), выполнить
   `npm ci && npm run db:deploy && npm run build`, запустить `npm start` под
   systemd или pm2 на порту 3000.
4. `Caddyfile` — три строки, HTTPS и WebSocket Caddy делает сам:

   ```caddyfile
   school.example.ru {
       reverse_proxy 127.0.0.1:3000
   }
   ```
5. Перенести данные из текущей базы: `pg_dump` на Render → `psql` на VPS,
   затем `npm run db:deploy` (применит миграции Prisma).
6. Перенести файлы из `storage/uploads` (сейчас они на эфемерном диске Render —
   см. `docs/security-hardening.md`, §2.4).

Как только переезд проверен, старый Render-сервис можно отключить: домен, ключи
ИИ и `NEXTAUTH_SECRET` остаются те же.

## Что делать пользователю прямо сейчас

Если сайт не открылся:

1. Обновить страницу один-два раза (холодный старт после сна).
2. Подождать до минуты — инстанс поднимается.
3. Если через минуту всё ещё «соединение сброшено» — это сетевой блок, а не сайт:
   написать владельцу и указать оператора связи (у разных операторов результат
   отличается).

## Как это проверить самому

```bash
# 1. Сервер отвечает?
curl -sS -o /dev/null -w '%{http_code} %{time_total}s\n' https://schoolmeet-vb96.onrender.com/api/health

# 2. Через какой узел идёт трафик?
getent hosts schoolmeet-vb96.onrender.com   # → *.cdn.cloudflare.net

# 3. Сравнить с VPN: если с VPN 200 и < 1 c, а без VPN таймаут — блок на сети.
```
