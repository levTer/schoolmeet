# EduFlow для macOS (Electron + DMG)

Десктопная обёртка EduFlow для Mac: нативное окно Electron, внутри — живая
веб-версия платформы. Установщик `.dmg` бесплатно собирает GitHub Actions на
macOS-раннере; самому Mac для сборки не нужен.

## Как устроено

```
electron-app/
├── main.js                  Окно, экран загрузки, навигация, разрешения, загрузки
├── loading.html             Экран загрузки (сервер Render «просыпается» до минуты)
├── package.json             Пакет eduflow-desktop + конфигурация electron-builder
├── package-lock.json        Зафиксированные версии electron / electron-builder
├── build/
│   ├── icon.png             Иконка 1024×1024 для .icns (источник: ../public/icon.svg,
│   │                        перегенерируется командой npm run icons:generate в корне)
│   ├── entitlements.mac.plist          Подпись камеры/микрофона под hardened runtime
│   └── entitlements.mac.inherit.plist  (сейчас сборка без подписи — см. ниже)
└── assets/
    └── icon.png             Тот же 1024×1024 для окна и экрана загрузки
                             (каталог build/ внутрь приложения не упаковывается)
.github/workflows/build-mac-dmg.yml     Автоматическая сборка DMG
```

Ключевые моменты `main.js`:

- открывает `https://schoolmeet-vb96.onrender.com` (переопределяется
  переменной окружения `EDUFLOW_URL`, например для `http://localhost:3000`);
- сначала показывает фирменный экран загрузки и дожидается пробуждения
  бесплатного сервера Render вместо пустого белого окна; если за 2 минуты
  сервер не ответил — кнопка «Повторить»;
- **безопасность**: `nodeIntegration: false`, `contextIsolation: true`,
  `sandbox: true`, preload нет — сайт работает как обычная веб-страница и не
  имеет доступа к системе; навигация разрешена только по origin'у платформы,
  внешние ссылки открываются в системном браузере;
- камера, микрофон и демонстрация экрана (WebRTC-уроки) разрешены только
  нашему сайту; на macOS 15+ выбор экрана рисует системный picker;
- загрузки идут через системный диалог сохранения, прогресс — на значке в Dock;
- сессия (вход в аккаунт) сохраняется между запусками, как в браузере;
- окно — без полос меню. На macOS остаётся минимальное системное меню
  в верхней строке экрана: без него macOS не отдаёт Cmd+C / Cmd+V / Cmd+Q.

Приложение имеет appId `com.eduflow.app`, имя `EduFlow`, собирается
**универсальным** (Intel + Apple Silicon одним файлом).

## Где взять готовый DMG

1. **GitHub Actions** → workflow **Build macOS DMG** → последний запуск →
   артефакт `EduFlow-macOS-dmg` (хранится 90 дней).
2. **GitHub Releases** — если сборка запущена по тегу `v*` (см. «Новая версия»),
   DMG прикрепляется к релизу. Постоянная ссылка на последний релиз:
   `https://github.com/levTer/schoolmeet/releases/latest/download/eduflow.dmg`
   — её можно поставить на кнопку Mac на лендинге вместо текущей инструкции.

> ⚠️ В папку `public/` на сайте DMG **не коммитится** (в отличие от маленьких
> APK/MSIX): универсальный Electron-образ весит ~100 МБ, а GitHub запрещает
> файлы в git больше 100 МБ. Шаг «Copy DMG to public» в workflow нужен, чтобы
> у файла было стабильное имя `public/eduflow.dmg` внутри раннера; наружу он
> уходит артефактом и релизом.

## Установка на Mac (приложение без подписи Apple)

Сборка не подписана сертификатом Apple Developer ($99/год), поэтому при первом
запуске macOS покажет «не удаётся проверить разработчика». Это нормально:

1. Откройте `eduflow.dmg`, перетащите **EduFlow** в «Программы».
2. Первый запуск: **правый клик по EduFlow → Открыть → Открыть**.
   (Если не помогло: «Системные настройки» → «Конфиденциальность и
   безопасность» → «Открыть всё равно».) В крайнем случае в Терминале:
   `xattr -dr com.apple.quarantine /Applications/EduFlow.app`
3. На уроке разрешите камеру и микрофон, когда macOS спросит. Для демонстрации
   экрана один раз включите «Системные настройки» → «Конфиденциальность и
   безопасность» → «Запись экрана и системного звука» → EduFlow и перезапустите
   приложение.

## Локальная разработка

Нужен Node ≥ 22.12. Окно запускается на любой ОС; `.dmg` собирается только на Mac.

```bash
cd electron-app
npm ci
npm start                                    # окно с живым сайтом
EDUFLOW_URL=http://localhost:3000 npm start  # окно с локальным dev-сервером
npm run dist:mac                             # DMG в dist/ (только на macOS)
```

## Новая версия DMG

DMG пересобирается автоматически при пуше в `main` (и вручную кнопкой
Run workflow). Если хотите постоянный релиз:

```bash
# Поднимите version в electron-app/package.json, затем:
git tag v1.0.1
git push origin v1.0.1
```

Workflow сам создаст GitHub Release и приложит `eduflow.dmg`.

## Подпись и нотаризация (будущее)

Когда/если появится аккаунт Apple Developer, подпись включается без переделки
проекта: entitlements уже лежат в `build/`, описания камеры/микрофона уже
прописываются в Info.plist (`extendInfo` в `package.json`). Останется добавить
в workflow секреты сертификата (`CSC_LINK`, `CSC_KEY_PASSWORD`) и данные
нотаризации (`APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID`),
убрать `CSC_IDENTITY_AUTO_DISCOVERY: "false"` и включить
`"hardenedRuntime": true` в конфигурации `mac`.
