EduFlow для Windows — портативная версия
=========================================

Что это
-------
eduflow-portable.exe — один файл, который открывает EduFlow в отдельном окне
приложения. Устанавливать ничего не нужно: ни прав администратора, ни MSIX,
ни сертификата издателя.

Как запустить
-------------
1. Распакуйте архив в любую папку, например на Рабочий стол.
   (Запускать прямо из ZIP-архива нельзя — Windows сначала распакует файл.)
2. Дважды щёлкните по eduflow-portable.exe.
3. Откроется окно EduFlow. Нужен интернет: приложение работает онлайн.

Если Windows покажет синее окно, нажмите 'Подробнее' -> 'Выполнить в любом случае'.

Это безопасно: приложение не подписано платным сертификатом издателя, поэтому
SmartScreen показывает предупреждение для любого нового неподписанного файла.
Антивирус проверять файл не запрещает — предупреждение SmartScreen не вирус.

Системные требования
--------------------
* Windows 10 или Windows 11 (64-битная).
* Microsoft Edge (есть в Windows по умолчанию) или Google Chrome —
  лаунчер открывает сайт EduFlow в режиме приложения: окно без адресной
  строки и вкладок. Если ни Edge, ни Chrome не найдены, сайт откроется
  в браузере по умолчанию.
* Интернет. Офлайн-режима у портативной версии нет.

Куда сохраняются данные
-----------------------
Лаунчер использует отдельный профиль браузера:
%LOCALAPPDATA%\EduFlow\Portable
Он не трогает ваш обычный профиль Edge/Chrome. Чтобы сбросить локальные
данные приложения, закройте окно EduFlow и удалите эту папку.

Удаление
--------
Портативная версия не пишет ничего в реестр и не ставит службы.
Удалите папку с eduflow-portable.exe — и всё.

Свой адрес сервера
------------------
Положите рядом с eduflow-portable.exe файл eduflow.url с одной строкой
(например, https://schoolmeet-vb96.onrender.com) — лаунчер откроет этот адрес.

Альтернативные способы установки
--------------------------------
* Браузер: откройте сайт EduFlow и выберите «Установить» (Chrome/Edge) —
  приложение появится в меню «Пуск» как PWA.
* MSIX-пакет (eduflow.msix) требует доверенного сертификата: на неподписанном
  пакете Windows выдаёт ошибку 0x800B010A. Поэтому используйте портативную версию.

Подробнее: windows-portable/README.md в репозитории проекта.
