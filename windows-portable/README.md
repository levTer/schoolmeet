# EduFlow для Windows: портативная сборка вместо MSIX

## Зачем

Неподписанный `eduflow.msix` Windows блокирует с ошибкой **0x800B010A**
(«Не удалось проверить подпись… требуется доверенный сертификат издателя»).
Доверенный сертификат подписи кода — платный, поэтому установка MSIX требует
покупки. Портативный `.exe` этой проблемы не имеет: его не нужно
регистрировать в системе, а предупреждение SmartScreen пользователь снимает
двумя кликами.

## Что отдаёт сайт

`public/eduflow-windows.zip` — архив с двумя файлами:

| Файл | Что это |
| --- | --- |
| `eduflow-portable.exe` | нативный Win32-лаунчер, ~90 КБ, без зависимостей |
| `Как запустить.txt` | инструкция (UTF-8 с BOM, чтобы «Блокнот» не ломал кириллицу) |

Ссылка на сайте — `/eduflow-windows.zip` с атрибутом `download`
(`src/components/landing/install-block.tsx`, `src/components/pwa-install-button.tsx`).
Service Worker (`public/sw.js`) не перехватывает `.zip` и `.exe`, поэтому архив
не подменяется закэшированным HTML при офлайне.

## Как устроен лаунчер

`windows-portable/launcher.c` — Win32 GUI-приложение (подсистема `WINDOWS`,
консоль не открывается). Алгоритм:

1. Адрес приложения: файл `eduflow.url` рядом с `.exe` (UTF-8/UTF-16LE), иначе
   вшитый по умолчанию (`EDUFLOW_URL` при сборке, по умолчанию
   `https://schoolmeet-vb96.onrender.com`).
2. Поиск Chromium-браузера: `App Paths\msedge.exe` / `chrome.exe` в реестре
   (`HKCU`, затем `HKLM`), затем стандартные каталоги Edge и Chrome.
3. Запуск `msedge.exe --app=<url> --window-size=1360,900 --user-data-dir=…`
   (`CreateProcessW`): окно без адресной строки и вкладок, отдельный профиль
   `%LOCALAPPDATA%\EduFlow\Portable` — обычный профиль браузера не затрагивается.
4. Если Edge/Chrome не найдены — `ShellExecuteW` открывает адрес в браузере по
   умолчанию. Если и это не удалось, показывается сообщение с адресом.

Иконка окна/панели задач и файла — иконка EduFlow (дизайн №9) из
`public/icon.svg` в слоях 16/24/32/48/64/128/256 px, плюс `VERSIONINFO`
(в «Свойствах» файла видно имя и версию EduFlow).

> Портативная версия — не офлайн-клиент: приложение работает онлайн, нужен
> интернет. Отдельный Chromium (как в Electron) сознательно не упаковывается —
> это +100 МБ в архив и ещё один канал обновлений.

## Сборка

Нужен [zig](https://ziglang.org/download/) (clang + lld + rc в одном файле,
кросс-компиляция с Linux/macOS/Windows):

```bash
pip install ziglang          # или скачайте бинарник и добавьте в PATH
npm ci
npm run build:windows        # → public/eduflow-windows.zip
```

Полезные переменные:

```bash
npm run build:windows -- --zig=/opt/zig/zig   # явный путь к zig
EDUFLOW_URL=https://example.com npm run build:windows
SOURCE_DATE_EPOCH=1700000000 npm run build:windows   # воспроизводимая дата в ZIP
```

Сборка сама проверяет результат и падает, если:

* подсистема PE не `WINDOWS` (иначе при запуске открылась бы консоль);
* в `.exe` нет секции `.rsrc`/`RT_GROUP_ICON` или слоёв 16/32/48/256;
* слой иконки в `.exe` не совпадает с текущим `public/icon.svg`;
* в ZIP нет `.exe` или инструкции с флагом UTF-8.

Те же проверки выполняет `npm run test:ui` для закоммиченного архива — если
меняете `public/icon.svg` или `launcher.c`, пересоберите архив и закоммитьте
`public/eduflow-windows.zip`.

Промежуточные файлы складываются в `windows-portable/build/` (в `.gitignore`).

## SmartScreen

Неподписанный `.exe` при первом запуске показывает синее окно SmartScreen:
**«Подробнее» → «Выполнить в любом случае»**. Это ожидаемое поведение, а не
вирус — так Windows реагирует на любой новый файл без подписи. Текст
предупреждения продублирован в модальном окне установки
(`src/lib/install-copy.ts`) и в `Как запустить.txt`.

Убрать предупреждение полностью можно только подписью кода (EV-сертификат и
накопленная репутация) — это и есть платный путь, от которого мы ушли.

## Проверка на Windows вручную

1. Скачать `eduflow-windows.zip` с сайта и распаковать.
2. Запустить `eduflow-portable.exe` → «Подробнее» → «Выполнить в любом случае».
3. Ожидаемо: окно EduFlow без адресной строки, иконка EduFlow на панели задач,
   профиль в `%LOCALAPPDATA%\EduFlow\Portable`.
4. Проверить `Свойства → Подробно` у `.exe`: имя продукта EduFlow и версия.
